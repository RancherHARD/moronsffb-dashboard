# Morons of the Gridiron Dashboard

Private family fantasy football league dashboard for Morons of the Gridiron XVIII (Yahoo league 444631).

This is a self-contained, mobile-friendly single-page site. All data is static and updated by replacing `index.html` with a new version when screenshots or new information arrive.

## How to update
1. Download the latest `index.html` from the chat or this repo.
2. Replace the existing `index.html` in the repository.
3. Commit and push (or upload via the GitHub web interface).
4. The live site updates in about a minute.

## Local viewing
Just open `index.html` in any browser.
